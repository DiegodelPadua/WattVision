## 📊 Estrutura Analítica do Projeto — EAP

A Estrutura Analítica do Projeto (EAP/WBS) foi desenvolvida de forma
interativa para facilitar a visualização das etapas e entregas do TCC.

### 🌐 Acessar EAP Interativa

👉 [Abrir EAP do Projeto](https://visual-wbs-flow.lovable.app)

A ferramenta permite visualizar a estrutura hierárquica do projeto,
expandir e recolher etapas e acompanhar a organização das entregas.
